### Быстрый старт
#### Запуск тестов в Jenkins
1. Открыть [джобу в Jenkins](https://jenkins.autotests.cloud/job/steam_store_ui_test/)

2. Нажать "**Build with Parameters**".
![джоба](img/jenkins/build.png)

3. Выбираем любой параметр и жмем "**Build**"
